Guide d'utilisation

L'application Feuille d'avant-match permet de préparer une composition d'équipe, de visualiser la formation sur un terrain et d'imprimer la feuille avant le match.

1. Afficher une composition

  1. Ouvrez l'application dans votre navigateur.
  2. Cliquez sur Charger la configuration.
  3. Sélectionnez un fichier au format .json.
  4. La feuille est actualisée automatiquement avec les informations du fichier.

Une configuration d'exemple est affichée au démarrage. Le chargement d'un fichier ne modifie pas le fichier original sur votre ordinateur.

2. Préparer le fichier JSON

Le fichier doit contenir les informations du match et la liste des joueurs. Voici un exemple complet : 

{
  "equipe": "EJPS 2 U14",
  "adversaire": "Alsasud",
  "lieu": "Stade Municipal",
  "domicile": false,
  "typeMatch": "Championnat J1",
  "date": "2026-09-12",
  "formation": "4-3-3",
  "joueurs": [
    { "playerId": 28, "numero": 1, "poste": "GB" },
    { "playerId": 11, "numero": 2, "poste": "DG" },
    { "playerId": 19, "numero": 10, "poste": "AG", "capitaine": true }
  ]
}

3. Champs du match

ChampDescriptionExemple
equipeNom de votre équipe.EJPS 2 U14
adversaireNom de l'équipe adverse.Alsasud
lieuLieu de la rencontre. Champ facultatif.Stade Municipal
domiciletrue si votre équipe joue à domicile, sinon false.false
typeMatchType ou journée du match.Championnat J1
dateDate au format ISO AAAA-MM-JJ.2026-09-12
formationNom de la formation affichée.4-3-3

4. Champs d'un joueur

ChampDescription
numeroNuméro porté par le joueur.
playerIdIdentifiant numérique du joueur dans data/players.json.
posteCode du poste. Les remplaçants utilisent R1, R2, etc.
capitaineOptionnel. Utilisez true pour afficher le badge du capitaine.

Les codes de postes reconnus pour le terrain sont notamment GB, DG, DD, DCG, DCD, MDC, MCG, MCD, AG, AD et AC. Un poste non reconnu n'est pas placé sur le schéma du terrain, mais reste visible dans la liste des joueurs.

5. Imprimer la feuille

Cliquez sur Imprimer, choisissez l'imprimante ou l'option d'enregistrement en PDF, puis confirmez. Pour un meilleur résultat, utilisez le format A4 et l'orientation recommandée par votre navigateur.

6. En cas de problème

  • Le fichier ne se charge pas : vérifiez qu'il s'agit d'un JSON valide et qu'il porte l'extension .json.
  • La date ne s'affiche pas correctement : utilisez strictement le format AAAA-MM-JJ.
  • Un joueur n'apparaît pas sur le terrain : vérifiez le code indiqué dans le champ poste.
  • Deux joueurs se superposent : l'application décale automatiquement les joueurs partageant le même poste ; vérifiez toutefois que les postes sont corrects.
