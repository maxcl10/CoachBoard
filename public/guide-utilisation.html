Guide d'utilisation

L'application Feuille d'avant-match permet de préparer une composition d'équipe, de visualiser la formation sur un terrain et d'imprimer la feuille avant le match.

1. Afficher une composition

  1. Ouvrez l'application dans votre navigateur.
  2. Cliquez sur Charger la configuration.
  3. Sélectionnez un fichier au format .json.
  4. La feuille est actualisée automatiquement avec les informations du fichier.

Une configuration d'exemple est affichée au démarrage. Le chargement d'un fichier ne modifie pas le fichier original sur votre ordinateur.

2. Préparer le fichier JSON

Le fichier doit contenir les informations du match et la liste des players. Voici un exemple complet : 

{
  "team": "EJPS 2 U14",
  "opponent": "Alsasud",
  "venue": "Stade Municipal",
  "home": false,
  "matchType": "Championnat J1",
  "date": "2026-09-12",
  "formation": "4-3-3",
  "players": [
    { "playerId": 28, "shirtNumber": 1, "position": "GB" },
    { "playerId": 11, "shirtNumber": 2, "position": "DG" },
    { "playerId": 19, "shirtNumber": 10, "position": "AG", "captain": true }
  ]
}

3. Champs du match

ChampDescriptionExemple
teamNom de votre équipe.EJPS 2 U14
opponentNom de l'équipe adverse.Alsasud
venueLieu de la rencontre. Champ facultatif.Stade Municipal
hometrue si votre équipe joue à home, sinon false.false
matchTypeType ou journée du match.Championnat J1
dateDate au format ISO AAAA-MM-JJ.2026-09-12
formationNom de la formation affichée.4-3-3

4. Champs d'un joueur

ChampDescription
shirtNumberNuméro porté par le joueur.
playerIdIdentifiant numérique du joueur dans data/players.json.
positionCode du position. Les remplaçants utilisent R1, R2, etc.
captainOptionnel. Utilisez true pour afficher le badge du captain.

Les codes de postes reconnus pour le terrain sont notamment GB, DG, DD, DCG, DCD, MDC, MCG, MCD, AG, AD et AC. Un position non reconnu n'est pas placé sur le schéma du terrain, mais reste visible dans la liste des players.

5. Imprimer la feuille

Cliquez sur Imprimer, choisissez l'imprimante ou l'option d'enregistrement en PDF, puis confirmez. Pour un meilleur résultat, utilisez le format A4 et l'orientation recommandée par votre navigateur.

6. En cas de problème

  • Le fichier ne se charge pas : vérifiez qu'il s'agit d'un JSON valide et qu'il porte l'extension .json.
  • La date ne s'affiche pas correctement : utilisez strictement le format AAAA-MM-JJ.
  • Un joueur n'apparaît pas sur le terrain : vérifiez le code indiqué dans le champ position.
  • Deux players se superposent : l'application décale automatiquement les players partageant le même position ; vérifiez toutefois que les postes sont corrects.
